01

GP Replay

Java 21 · Spring Boot · WebSocket · React 19 · PostgreSQL · Python

Replays historical Formula 1 races through an interactive circuit map, a live timing tower and synchronised driver telemetry — speed, RPM, gear, throttle, brake, DRS — with playback from 1× to 40×.

The decision that mattered. The replay service never rebuilds race state while streaming. A Python ETL precomputes one JSON snapshot every 200 ms into a replay_ticks table, so playback is an indexed range read and seeking stays predictable at any speed.

02

AskMyRepo

Go · SQLite · Ollama · no CGO

Indexes a local repository into SQLite, retrieves relevant code by combining vector, keyword and identifier signals, and streams file-and-line-cited answers from a model running locally through Ollama.

The constraint that shaped it. No Docker, no CGO, no framework, no external API — Go standard library and modernc.org/sqlite only. Incremental SHA-256 indexing re-embeds just the changed chunks; bounded worker pools keep local embedding from saturating the machine. Retrieval scores cosine similarity alongside keyword and identifier matching.
